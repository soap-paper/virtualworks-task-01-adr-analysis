# VirtualWorks Lab Internship — Task 1
## Adverse Drug Reaction (ADR) Case Analysis

This repository contains my submission for **Task 1 of the VirtualWorks Lab internship**.

The project uses five simulated patient case scenarios to demonstrate a basic, structured approach to adverse drug reaction assessment.

### What is included

- **ADR_Case_Analysis_Report.pdf** — the final written case-analysis report.
- **ADR_Case_Analysis.xlsx** — the working case summary and causality assessment sheet.

### Cases covered

| Case | ADR mechanism |
|---|---|
| ADR-001 | Pharmacological / predictable |
| ADR-002 | Pathological / toxic |
| ADR-003 | Allergic / hypersensitivity |
| ADR-004 | Pharmacogenetic / idiosyncratic |
| ADR-005 | Teratogenic / developmental toxicity |

### Assessment approach

For each case, the review considers:

- Patient and reaction details
- Suspected medicine and indication
- Dose, route and frequency
- Concomitant medicines and other exposures
- Temporal relationship
- Clinical/pharmacological plausibility
- Dose-response where applicable
- Dechallenge
- Rechallenge considerations
- Management and outcome
- Final WHO-UMC causality assessment

### Disclaimer

**All patient profiles, clinical events, dates, manufacturers and batch information used in this repository are fictional/simulated training data.** They do not represent real patients or real pharmacovigilance reports.
